# 翔太の成長物語 Ultimate - Sound Novel

## プロジェクト概要
才能の壁にぶつかった中学生剣士・翔太が、現代に蘇った宮本武蔵の霊との出会いを通じ、「素直さ（コーチャビリティ）」を単なる性格としてではなく、勝利を掴むための「合理的技術」として再定義し、圧倒的な成長を遂げる物語を体験できるブラウザ向けノベルゲームです。

## コアテーマ
「素直さとは、最短で『間違ったやり方』を棄却する技術である」

## ゲームの特徴 (Ultimate Edition)
- **フルブラウザ動作**: HTML5 / CSS3 / Vanilla JS で構築されており、環境構築なしでブラウザさえあればどこでもプレイ可能です。
- **リッチな視覚エフェクト**: モノクローム演出、画面のシェイク、マイナス感情のフラッシュ表示など、主人公の心理状態に合わせた動的なWebエフェクトを搭載。
- **充実のノベルゲームシステム**: 
  - オートプレイ機能（自動テキスト送り）
  - ログ（履歴）機能と、任意の過去のセリフへの巻き戻し（リワインド）機能
  - 難しい言葉（心理学用語や剣道の概念など）のオンマウス・解説ツールチップ機能
- **「メタ認知ノート」の完全収録**: 各章の終わりに、翔太が自身の行動を【事実】【感情】【学び】【改善点・決意】に分解して書き留める「15分のリフレクション（振り返り）」をノーカットで完全収録。

## 起動・プレイ方法
1. このリポジトリを手元にクローンまたはダウンロードします。
2. `webapp` ディレクトリ内の `index.html` をブラウザで直接開くか、VS CodeのLive Server等のローカルサーバーで起動してください。
3. （GitHub Pagesで公開されている場合は、指定のURLから即座にプレイ可能です）

## フォルダ構成
- `webapp/`: Webアプリケーションのソースコード実体 (`index.html`, `style.css`, `engine.js`, `scenario.js` など)
- `ultimate/`: シナリオのフルテキスト書き起こし原稿 (Markdown形式)
- `Requirements.md` / `Characters.md`: 世界観・登場人物・初期要件定義ファイル
